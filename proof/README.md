# Proofs: GermaineTutoring Editorial Theme Mockup

This directory contains visual proof of the 3 main layout states (Marketing, Course, and Blog) evaluated at both Desktop (1280px) and Mobile (375px) viewports, plus an interaction walkthrough.

## Still Image Proofs

| File Path | Viewport | Panel/Tab | State Proven |
| :--- | :--- | :--- | :--- |
| `1280/tab-marketing.png` | Desktop (1280px) | 1 (Marketing) | Verifies the editorial typography and high-contrast Emerald/Paper design structure is applied to the marketing index, methodology, and consult form. |
| `1280/tab-course.png` | Desktop (1280px) | 2 (Course Portal) | Verifies the dense product UI retains editorial aesthetics with the Emerald-dark sidebar, and correctly formats course modules, WAJ, practice dashboard, and library. |
| `1280/tab-blog.png` | Desktop (1280px) | 3 (Blog & Campaign) | Verifies the 3-column Journal & Insights grid and centered editorial campaign layout with proper typography and whitespace scaling on desktop. |
| `375/tab-marketing.png` | Mobile (375px) | 1 (Marketing) | Verifies the marketing site grid-columns correctly collapse to 1fr and components adapt smoothly for mobile view without horizontal overflow. |
| `375/tab-course.png` | Mobile (375px) | 2 (Course Portal) | Verifies the course application cleanly transitions its sidebar navigation and course content panels into a mobile-friendly view. |
| `375/tab-blog.png` | Mobile (375px) | 3 (Blog & Campaign) | Verifies the blog index cards stack vertically (1fr grid) and the campaign post padding/typography reduce properly for smaller screens. |
